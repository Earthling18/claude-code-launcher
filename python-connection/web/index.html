订阅支持范围

订阅节点在本机连接，无需云服务器或 Clash。支持 SS AEAD（含 HTTP 混淆）和 AnyTLS TCP；其他协议会标注不支持。AnyTLS 使用标准 TLS，空闲连接最多保留 30 秒以便复用。遇到证书错误不会自动关闭校验或改为直连。

编辑当前连接与分流规则

日常使用不用修改这里。连接、认证和规则变更只影响之后打开的应用。

连接设置

更换认证时同时填写用户名和密码。不会显示已保存的密码，也不会修改系统路由。

分流规则

规则模式：阻止 → 强制代理 → 显式直连 → 公司 DNS → 国内规则 → 默认动作。每行一条域名或网段。

公司 DNS

仅对当前方案生效。匹配的公司域名只使用这里的 DNS，失败不会改用公共 DNS。清空两项可关闭。

修改只影响新启动的会话。
客户端启动选项

沿用模式不复制、合并或改写原配置文件，只在本次进程中设置代理。程序本身仍正常保存会话。需要完整退出原客户端后再打开，不会强制结束现有窗口。

独立测试窗口仅用于排错；它拥有自己的历史和登录。窗口内的真实模型请求仍需验收。

如果弹出本地代理认证框
